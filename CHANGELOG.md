# Changelog

Notable changes to Stochastic Program IR are recorded here. The project follows
semantic versioning, including prerelease identifiers while the API is in
alpha.

## 0.1.0a1 - 2026-07-29

- Added the initial typed, immutable random-variable expression algebra.
- Added named sampling and broadcasting plates with explicit reductions.
- Added phased, reproducible materialization and structural and stochastic
  equality.
- Added normal, uniform, and Bernoulli sampling with support validation and
  NumPy execution.
- Added package, documentation, artifact, and cross-version CI validation.
- Added secretless Trusted Publishing through TestPyPI and PyPI release gates.
- Adopted the BSD 3-Clause License.
